# 🎟️ Ticket Booking & Payment App

Інтерактивний React-додаток для онлайн-вибору, бронювання та оплати квитків на сеанс. Проєкт демонструє практичне застосування сучасних React-бібліотек, роботу зі станом, контроль активності користувача та валідацію платіжних даних.

## 📋 Про проєкт

Користувач проходить повний цикл бронювання квитка:
1. **Вибір дати сеансу** за допомогою інтерактивного календаря.
2. **Вибір місця в залі** на інтерактивній схемі місць.
3. **Введення платіжних реквізитів** з інтерактивною візуалізацією банківської картки, яка анімовано реагує на введення та перевертається при заповненні CVC-коду.
4. **Контроль часу сесії**: у разі бездіяльності користувача протягом 20 секунд сесія скидається задля безпеки та звільнення зарезервованого місця.

## 📚 Використані бібліотеки та їх обґрунтування

### 1. Обов'язкові бібліотеки

* **[React Icons](https://react-icons.github.io/react-icons/) (`react-icons`)**
  * **Призначення:** Додавання векторних іконок для покращення UI/UX.
  * **Використання в проєкті:** Іконки квитка (`FaTicketAlt`), календаря (`FaCalendarAlt`), крісел у залі (`FaChair`), годинника сесії (`FaClock`), платіжної картки (`FaCreditCard`), сповіщень успіху (`FaCheckCircle`) та попередження (`FaExclamationTriangle`).

* **[React Toastify](https://fkhadra.github.io/react-toastify/) (`react-toastify`)**
  * **Призначення:** Спливаючі нотифікації користувачеві про статус дій без блокування інтерфейсу.
  * **Використання в проєкті:** Повідомлення про вибір місця (`toast.info`), валідацію незаповнених полів картки (`toast.error`), скидання сеансу через неактивність (`toast.warn`) та успішне завершення бронювання (`toast.success`).

* **[React Idle Timer](https://idle-timer.doulen.dev/) (`react-idle-timer`)**
  * **Призначення:** Відстеження пасивності користувача (відсутність рухів миші, натискань клавіш, скролу).
  * **Використання в проєкті:** Хук `useIdleTimer` налаштовано на таймаут 20 секунд. Якщо користувач не здійснює дій, бронювання місця автоматично скасовується, форма блокується та виводиться попереджувальне сповіщення.

### 2. Додаткові бібліотеки

* **[React Credit Cards 2](https://github.com/styleshout/react-credit-cards-2) (`react-credit-cards-2`)**
  * **Обґрунтування:** Наочна та естетична візуалізація банківської картки в реальному часі.
  * **Використання в проєкті:** Динамічно відображає введені номер картки, ім'я власника, термін дії та CVC/CVV. При фокусі на полі введення CVC картка автоматично перевертається на зворотний бік.

* **[React Datepicker](https://reactdatepicker.com/) (`react-datepicker`)**
  * **Обґрунтування:** Зручний та доступний UI-компонент вибору дати з підтримкою локалізації та гнучких обмежень.
  * **Використання в проєкті:** Дозволяє обрати дату сеансу, блокуючи вибір минулих дат за допомогою `minDate={new Date()}`.

## 🚀 Встановлення та запуск

### Попередні вимоги
- **Node.js** (версія 18.x або вище)
- **npm** (версія 9.x або вище)

### 1. Клонування репозиторію
```bash
git clone https://github.com/<ваш-username>/<назва-репозиторію>.git
cd react-icon
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск у режимі розробки
```bash
npm run dev
```
Після запуску відкрийте браузер за адресою: **http://localhost:5173**

### 4. Збірка для продакшену
```bash
npm run build
```

### 5. Перевірка коду (Лінтер)
```bash
npm run lint
```
